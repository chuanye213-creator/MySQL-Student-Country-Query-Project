MySQL 数据查询与统计分析项目
项目简介
本项目为金融科技专业课程作业，基于 MySQL 数据库完成学生信息与国家人口数据的多维度查询、统计与分析，覆盖 SQL 核心语法，可直接复现运行。

## 项目背景
使用 MySQL 对两张数据表进行操作：
- `student`：包含学生基本信息与语文、英语、数学成绩
- `country`：包含国家ID、名称与人口数据（单位：百万）

## 实现功能
### 1. 学生信息查询与统计
- 基础查询：字段筛选、去重、别名、计算总分
- 条件筛选：不等、区间、列表、模糊匹配（姓名匹配）
- 分组聚合：按性别/年龄/地址分组，统计平均分、最高分、人数
- 排序：按成绩、总分升序/降序排序

### 2. 国家人口数据分析
- 人口筛选：统计超5千万/1亿人口的国家
- 区域统计：东亚国家人口汇总与平均值计算
- 分段统计：排名区间内的人口数据筛选
- 大洲人口汇总：手动划分大洲，统计各大洲总人口
